Know the assumptions

A five-star resets pity. An unguaranteed five-star has a 50% chance to be featured. An off-banner five-star guarantees the next five-star is featured; a featured acquisition clears that guarantee.

The default model uses 0.8% on pulls 1–79 and 100% on pull 80. It omits soft pity and does not reproduce the published 1.8% aggregate five-star rate.

Illustrative soft pity adds the selected increase starting on the selected pull, capped at 100%. Defaults: 6.8% on pull 66, 12.8% on pull 67, and so on. This is not an official or fitted probability curve.

“Exact” means exact for the chosen mathematical assumptions, up to rounding. The simulation interval measures sampling uncertainty only. Neither validates the assumed game rules. Means include all trials, including those exceeding the budget.

Four-star outcomes, weapon banners, store purchases and coral refunds are excluded. The browser simulator uses a seeded generator; its samples differ from the Python app.

Check current in-game details before applying these estimates.
